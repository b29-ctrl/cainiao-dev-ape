先读我
======

这个包里是「菜鸟开发猿」（原名 dev-workflow-1n1n）——一套「1 主理人 + N 小组队长 + N AI」的通用开发流程。

════════════════════════════════════
  你是「人」还是「AI」？先认这条
════════════════════════════════════

【如果你是人（主理人）】从这里开始 ↓

  1. 技能简介.html   ← 双击打开，5 分钟看懂这是什么
  2. SKILL.md        ← 3 分钟上手，怎么装、怎么跑
  3. 01_流程/20261107_通用开发流程_v4.45.md  ← 规则本体，按需查（不用通读）

  流程顺序：S-1 → S0…S4 冻结 → S4.5 接入调度台 → S5 方案【门①】→ S6。
  S4.5 不是新门禁：有调度台就建项目交接；没有调度台走 S4.5-Lite，用 03_模板/S4_接入卡.md 人工交接。

  想直接跑起来（需要 Python 3.9+，不用装任何库）：
    Windows:        python 02_工具\启动项目.py --dir "你的项目" --port 8792
    macOS / Linux:  python3 02_工具/启动项目.py --dir ~/你的项目 --port 8792

  只改了几个字？那不用上流程，直接改就行。

【如果你是 AI（被交付方）】从这里开始 ↓

  ⚠️ 不要照着上面的"人"的路径走——你会直接起工具、跳过必做的 S-1 环境初始化。

  1. 先读「给AI的启动指令.md」，那是给你的完整指令
  2. 按它先做 S-1 四问（选模型 / 定 AI 数量 / 分配角色 / 指定目录）
  3. 每阶段做完停下等主理人确认，不要一口气跑完
  4. S4 冻结后进入 S4.5：把 S4 产物/00_环境.md 交接给调度台，停在门①等大BOSS拍板

════════════════════════════════════

【触发词】装好后说「立项 / 开工 / 走开发流程」即可激活；S4 冻结后说「接入调度台 / 交给调度台 / 派单」进入 S4.5，详见 SKILL.md 第一节。

注意：包里的示例数据（一卡通、进销存、值班表）都是虚构的，只用于演示结构。
