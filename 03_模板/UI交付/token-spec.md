# Token 规范（菜鸟开发猿 v4.64 · `03_模板/UI交付/`）

> 目标：**改主题只改 `:root`，组件不动。** 组件里出现 hex 或魔法数字即视为缺陷。
> 配套模板：`theme.template.css`（复制即用，只改第二层）。

## 1. 双层结构

```
第一层  原始色板    --coral-500 / --teal-400 / --ink-900   ← 只在这里出现具体色值
第二层  语义 token  --brand / --danger / --surface / --text  ← 组件只用这一层
```

做法：第一层用注释分组；第二层用 `var()` 引用第一层。切换主题只覆盖第二层（暗色只需改 12–20 个值）。

## 2. 命名规则

| 类别 | 前缀 | 示例 |
|---|---|---|
| 品牌/强调 | `--brand` `--brand-light` `--brand-soft` | `--brand:#FF6B6B` |
| 文字 | `--ink` `--ink-2` `--muted` `--faint` | 四级足够，不要更多 |
| 背景 | `--bg` `--surface` `--surface-solid` `--surface-hover` `--surface-dim` | 区分玻璃/实底/悬停/低对比块 |
| 描边 | `--line` `--line-dash` | 实线/虚线两档 |
| 状态 | `--success` `--warning` `--danger` `--info` + 各自 `-soft` + 各自 `-deep` | `-soft` 作底，`-deep` 作文字 |
| 字号 | `--fs-12` … `--fs-28` | 与像素值同名，避免记忆负担 |
| 圆角 | `--radius-xs/s/m/l/xl/pill` | 8/12/16/22/28/999 |
| 间距 | `--sp-1` … `--sp-8` | 4 的倍数 |
| 阴影 | `--shadow-1/2/3` `--shadow-focus` | 卡片 / 悬浮 / 聚焦环 |
| 动效 | `--dur` `--ease` | 180ms / cubic-bezier(.2,.8,.2,1) |

## 3. 色板约束

- **状态色必须有三个变体**：原色（色块）、`-soft`（浅底）、`-deep`（文字）。只有原色就会在浅底上读不清。
- **对比度**：正文对背景 ≥ 4.5:1；纯装饰文字（页脚版本号）不豁免，也不能低于 3:1。
- **彩色底上的文字**统一用 `--ink`（深墨），不要用白色。唯一例外：品牌 LOGO、深色消息气泡（后者需实测）。
- **渐变只用于大面积底**（页面背景、进度条），不要用在按钮上做渐变描边——hover/disabled 三态会难统一。

## 4. 字号阶梯

| Token | 值 | 用途 |
|---|---|---|
| `--fs-12` | 12px | 辅助信息下限（时间、计数、提示） |
| `--fs-13` | 13px | 正文主字号 |
| `--fs-14` | 14px | 小标题、按钮 |
| `--fs-17` | 17px | 卡片标题 |
| `--fs-22` | 22px | 页面标题 |
| `--fs-28` | 28px | 数字强调 |

字号**只允许这 6 档**：`12 / 13 / 14 / 17 / 22 / 28`（px）。

- **11px、11.5px 一律禁**：11.5 看着精致，在 1 倍屏上发虚，统一提到 12px（这是铁律 3「字号下限 12px」的原话）。
- **唯一例外：聊天气泡正文 13.5px**。用之前必须在规范里写明「仅此一处」，别扩散到别处。
- 除此之外的碎值（15 / 16.5 / 19……）也都不用，就近归到上面 6 档。

## 5. 间距与圆角

- 间距只用 4 的倍数：4 / 8 / 12 / 16 / 24 / 32。
- 圆角跟着"容器层级"走：页面 28、卡片 22、内块 16、控件 12、小标签 8、chip 药丸 999。**同一层级不要混用两档圆角。**
- 卡片间距 14px 左右比 16px 更紧凑，视觉上更"成组"。

## 6. 暗色占位

```css
/* [data-theme="dark"] { 仅覆盖第二层语义 token } */
```

第一版不做就只留这一行注释，**不要**写一半暗色——半套暗色比没有更糟。

## 7. 自检（Windows 示例）

```powershell
# 组件文件里不得出现 hex（排除 :root 所在文件）
Select-String -Path app.css -Pattern '#[0-9a-fA-F]{3,8}\b' -AllMatches

# var 使用与定义对齐：把 var(--x) 去重后与 :root 定义做差集，结果应为空
```

完整命令见同目录 `verify-playbook.md`「一查」；没有 PowerShell 就用编辑器全局搜索 `#` + 3–8 位十六进制。
